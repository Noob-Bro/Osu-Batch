> [!WARNING]
> **安全提示**

本仓库为 **UI 修复与中英文界面切换版本（2026-09-09）**，同时保留高级筛选功能。

源码位于仓库根目录。Windows x64 免安装版请从 **Releases** 下载，完整解压后运行：

```text
OsuBatch.exe
```

**源码启动：** 克隆或下载源码到可写目录，然后双击 `start.cmd`。

需要 Python 3.12+。如果缺少依赖，首次运行会在项目目录中创建 `.venv`，并从 PyPI 安装所需依赖。后续启动无需重复安装。

升级前请先关闭旧版程序。已有下载队列和设置会继续保留。

**Language / 界面语言：** 在主窗口右上角选择 **中文** 或 **English**，切换后立即生效并自动保存偏好。

用户输入、谱面标题和艺术家名称始终保持原文。筛选值与下载状态不会因为显示语言切换而改变。

## 按条件批量下载

点击主窗口中的 **筛选搜索 / 批量下载**。

例如：

1. 搜索来源选择 `osu! 官方`。使用前请先在主窗口设置官网会话；也可以手动选择无需登录的 `Sayobot 小夜`。
2. 艺术家填写 `Laur`，选择 **精确匹配**。
3. 状态选择 `Ranked`，模式选择 `osu! standard (std)`。
4. 点击 **搜索全部分页**，查看艺术家、曲名、谱师、状态及包含的模式。
5. 搜索完成后点击 **全部加入下载队列**，返回主窗口并点击 **开始 / 继续**。

如果主窗口当前已经处于下载状态，新加入的任务会自动继续排队执行。

**搜索来源**与**下载来源**彼此独立。

例如，可以使用 Sayobot 搜索谱面，然后再使用主窗口设置的官方来源进行下载。程序不会自动更改搜索来源。

新版继续沿用原有队列数据库。升级前请先关闭旧版本。

### 筛选语义

* **精确艺术家匹配**会忽略大小写、首尾空格和全角/半角字符差异，并同时核对普通艺术家字段与 Unicode 艺术家字段。`Laur feat. Sennzai`、`Laurinha Costa` 均不等于 `Laur`。
* **包含匹配**可能包含合作曲，也可能包含 `Laura` 等相似名称，请结合预览结果判断。程序不会自行推断艺名或别名。艺术家字段留空表示不限。
* `Ranked` 严格指状态为 `ranked` 的谱面，不会混入旧的 `approved`。`Approved` 可以单独选择。
* 模式筛选表示该谱面集至少包含一个对应模式的原生难度。混合模式谱面集也可能入选。下载时仍然获取完整 `.osz`，不会删除其他模式的难度。
* 官网的游标分页与 Sayobot 的 `endid` 分页分别处理。程序会自动去重，并再次核对返回结果的艺术家、状态和模式。
* 官网未登录或会话失效时，网站可能忽略搜索条件并返回默认列表。工具会尝试识别这种情况并拒绝使用该结果。
* 搜索被取消、出现网络错误、分页重复或官网返回数量不足时，不会被标记为完整搜索，**全部加入**按钮会保持禁用；但仍可以明确选中当前已有的部分结果并加入队列。
* **全部**仅代表当前所选搜索来源在此次搜索中提供的全部分页。镜像可能存在同步延迟；官网结果也可能受到账号屏蔽列表、内容下架、搜索结果数量上限或搜索期间数据变化的影响，因此不能保证获得跨来源、跨时间意义上的绝对全集。搜索结束后，新谱面不会被自动追加。
* 官网搜索会包含带 NSFW 标记的谱面，以避免无提示漏项。程序只显示文本元数据，不显示封面。

## 快速开始

解压 Windows 免安装版本后运行：

```text
OsuBatch.exe
```

目标平台：

* Windows 10 22H2 64 位
* Windows 11 64 位

本版本已在 Windows 11 上进行验证。

1. 选择保存位置。
2. 默认下载策略为 **仅官方**。点击 **设置官网会话**，按照窗口提示提供你自己的官网 Cookie。会话仅在当前程序运行期间存在。
3. 粘贴谱面集链接或 ID，或者导入 UTF-8 编码的 TXT 文件，然后点击 **加入队列**。
4. 点击 **开始 / 继续**。如果需要使用镜像，可在下载策略中选择自动回退或仅使用镜像。
5. 下载完成后，将 `.osz` 文件拖入 osu!。

本工具不会直接修改 osu!stable 的 `Songs` 文件夹，也不会操作 osu!lazer 的内部文件存储。

## 下载来源由用户决定

| 策略                 | 行为                                                      |
| ------------------ | ------------------------------------------------------- |
| **仅官方（默认）**        | 仅向 osu! 官网发起下载请求，需要有效的网页登录会话                            |
| **官方优先，失败后尝试所选镜像** | 官网连接失败、登录失效或不可用时，可以尝试指定镜像；未设置官网会话时直接尝试镜像                |
| **仅所选镜像**          | 使用 Sayobot 小夜、Nerinyan 或 Mino (`catboy.best`)，且不会发送官网会话 |

遇到 HTTP `429` 限流时，程序会遵守 `Retry-After` 等待要求。

同一来源的并发任务共享冷却时间。连续三次失败后，任务会被标记为失败。程序不会仅因为限流而自动切换下载来源。

默认并发数为 `1`，最大为 `3`。新的下载请求之间至少间隔约 `1.5` 秒。

**不含视频**支持：

* osu! 官方
* Sayobot
* Nerinyan

选择 Mino 时，此选项会被禁用。服务器是否实际提供无视频版本由对应来源决定。

## 官方登录方式与限制

osu! 官方公开文档说明：标记为 `lazer` 的接口不向普通 Authorization Code / Client Credentials OAuth 应用开放。

因此，本工具使用官网已有的网页登录下载路由，不要求用户创建 OAuth 应用。

本工具**不会要求你输入 osu! 账号密码**。

### 设置官网会话

1. 使用你自己的浏览器登录 [osu! 官网](https://osu.ppy.sh/home)。
2. 打开任意谱面集页面。
3. 按 **F12**，打开 **Network / 网络**。
4. 点击官网的 **下载** 按钮。
5. 找到 `osu.ppy.sh` 域名下符合以下形式的请求：

```text
/beatmapsets/数字/download
```

6. 在 **Request Headers / 请求标头** 中复制 `Cookie` 的值，并粘贴到 osu! Batch 的会话设置窗口。

也可以：

1. 打开 **Application / 应用程序 → Cookies → https://osu.ppy.sh**
2. 复制 `osu_session` 的值。

> [!IMPORTANT]
> Cookie 相当于当前已经登录的会话凭据。
>
> **不要发送给其他人，也不要粘贴到聊天、Issue、截图或公开日志中。**

Cookie 只保存在当前程序进程的内存中。

以下内容均不会保存 Cookie：

* 配置文件
* 下载队列数据库
* 错误消息

关闭程序后需要重新设置会话。

Cookie 只发送至：

```text
https://osu.ppy.sh:443
```

如果下载请求跳转到文件服务器，程序不会继续携带 Cookie。

官网可能要求浏览器验证，也可能拒绝非浏览器网络客户端。

复制浏览器会话并不能保证绕过此类限制，本工具也不会自动处理这些验证机制。

如果遇到 HTTP `401` 或 `403`：

1. 在浏览器中重新登录 osu!。
2. 完成官网要求的验证。
3. 再次设置会话。

如果仍然无法使用官方来源，可以由用户自行选择镜像。

按钮显示：

```text
会话已设置 · 未验证
```

仅表示程序已经接受了输入内容。在实际完成一次官方来源下载之前，程序不会宣称当前登录会话已验证有效。

## 输入格式

支持例如：

```text
https://osu.ppy.sh/beatmapsets/123456#osu/789012
https://osu.ppy.sh/s/234567
345678
456789, 567890
```

规则：

* 纯数字始终按 **Beatmapset ID（谱面集 ID）** 解释。
* 下载完整谱面集。
* 同一个谱面集下的不同难度链接会自动去重。
* 首版不会解析仅包含单个难度 ID 的 `/beatmaps/123` 或 `/b/123` 链接。请打开官网并复制包含 `beatmapsets` 的完整链接。
* 同一队列中已经存在的 ID 不会重复加入。
* 如果需要重新下载已经完成的任务、修改目录或切换是否包含视频，请先移除原任务记录，再重新加入队列。
* 去重仅检查当前下载目录中由本工具生成的文件名。程序不会扫描游戏曲库，也不会检查服务器上是否已经存在更新版本的谱面。

## 暂停、续传和校验

* 暂停与取消都会保留 `.part` 临时文件。
* 被取消的任务不会自动恢复，可使用 **重试失败 / 已取消** 继续。
* 关闭程序时会先停止下载，然后保存队列。
* 正在等待网络响应时，正常情况下最多需要约 20 秒完成退出；多次跳转等特殊情况下可能更久。
* 只有当来源、谱面集和视频选项一致，并存在可用的 `ETag` 或 `Last-Modified` 时，程序才会发送续传请求。
* 如果服务器忽略 `Range`、返回不一致的 `Content-Range` 或无法安全续传，程序会重新下载，以避免把不同版本的数据错误拼接在一起。
* 下载完成后，会读取压缩包全部条目并验证 CRC。
* 同时检查 `.osu` 文件格式。
* 如果存在有效的 `BeatmapSetID` 字段，会核对其是否与请求 ID 一致。部分旧谱面可能缺少该字段，此时无法依赖此字段确认 ID。
* 文件只有通过校验后才会从临时文件改名为 `.osz`。
* 单个压缩包最大允许 **2 GiB**。
* 解压后的总内容最大允许 **4 GiB**。
* 校验过程中不会把压缩包实际解压到磁盘。
* 如果目标位置已经存在同名文件，会先进行校验。文件有效则直接跳过；文件无效则报告错误，同时保留用户原文件。
* 普通文件名：

```text
谱面集ID.osz
```

* 无视频版本：

```text
谱面集ID-novideo.osz
```

* **移除选中记录**只会删除队列中的任务记录，不会删除 `.osz` 文件或临时文件。
* 不再需要的 `.part` 文件及对应 `.json` 文件，可以在关闭程序后手动删除。

队列与设置默认保存在：

```text
%LOCALAPPDATA%\OsuBatch\queue.sqlite3
```

开发和测试时，可以使用：

```text
OSU_BATCH_DATA_DIR
```

指定其他数据目录。

程序使用单实例锁，以避免多个程序实例同时写入相同队列。

## 源码运行

需要 Python 3.12+。

在源码目录执行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

### 开发验证与打包

```powershell
.\.venv\Scripts\python.exe -m pip install pytest==9.1.1 pyinstaller==6.22.2
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe build.py
```

便携版输出目录：

```text
dist/OsuBatch/
```

发布时应分发**整个文件夹**，而不是只发送 `OsuBatch.exe`。

程序使用 PyInstaller 的 `onedir` 动态库布局，以便必要时替换依赖库。

第三方组件继续遵循各自的许可证。

## 文件结构

* `app.py`：桌面界面与线程任务调度。
* `engine.py`：下载来源适配、重试、续传和内容校验。
* `store.py`：下载队列与设置的持久化存储。
* `search.py`：官网与 Sayobot 分页搜索、本地筛选以及搜索完整性判断。
* `search_dialog.py`：筛选窗口、结果预览和加入队列。
* `tests/`：下载异常、凭据隔离、持久化及界面流程测试。
* `build.py`：Windows 便携版构建入口。
* `OsuBatch.spec`：PyInstaller 依赖收集规则，并排除构建环境中可能冲突的 ICU 动态库。
